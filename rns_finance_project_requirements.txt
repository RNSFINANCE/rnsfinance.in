# RNS Finance - Loan Management Portal Requirements

## 1. User Journey
- **Home Page**: Services overview, "Apply Now" CTA.
- **Login/Registration**: OTP-based mobile authentication (100% free).
- **Loan Application**: Personal details (Name, Address, Mobile, Email), Identity (PAN, Aadhar), and Document Uploads (Profile Pic, Doc Photos).
- **User Dashboard**: 
    - Application Status (Pending, In-Review, Rejected).
    - EMI Schedule (Total amount, monthly EMI, dates).
    - Payment Status (Paid with Green Tick ✔️).

## 2. Admin Portal (/admin)
- **Dashboard**: Overview of total applications and pending reviews.
- **Application Review**: Detailed view of user forms and uploaded documents.
- **Decision Engine**: Approve/Reject buttons.
- **Loan/EMI Setup**: Define EMI amounts and installment counts upon approval.
- **Payment Verification**: Manual "Mark as Paid" feature for EMI installments.
